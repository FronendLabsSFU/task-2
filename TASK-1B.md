# Задание 1B. Превращаем карточку в полноценную страницу

## Что вы сделаете

Продолжите проект из задания 1A. Карточка мероприятия уже готова. Теперь нужно добавить структуру страницы, навигацию, спикеров, расписание и контакты.

CSS писать не нужно: все стили и БЭМ-классы уже подготовлены.

Ожидаемый результат находится в `preview/expected-result.png`.

## С чего начать

1. Откройте `starter/index.html`.
2. Найдите комментарии `ШАГ 1` — `ШАГ 12`.
3. Откройте рядом файл `starter/content.md`: в нём находятся тексты, ссылки и названия классов.
4. Выполняйте шаги сверху вниз и после каждого этапа обновляйте страницу в браузере.

## Этап 1. Структура и навигация

- замените отмеченные внешние `div` на `header`, `main`, `section` и `footer`;
- добавьте `nav`;
- внутри навигации создайте список из четырёх ссылок;
- ссылки должны вести к разделам `#about`, `#speakers`, `#schedule`, `#contacts`.

Не меняйте готовые классы: внешний вид от тега не зависит, но смысл HTML изменится.

## Этап 2. Спикеры

- карточку спикера оформите через `article`;
- оставьте готовую карточку Анны Вороновой;
- добавьте карточки Максима Ильина и Дарьи Ким из `content.md`.

## Этап 3. Расписание

В готовом `table` создайте:

- `caption`;
- `thead` со строкой заголовков;
- `tbody` с семью строками расписания;
- `th` с `scope="col"`;
- обычные ячейки `td`.

Все данные и классы находятся в `content.md`.

## Этап 4. Контакты

- добавьте `address`;
- создайте список контактов;
- сделайте электронную почту ссылкой `mailto:`;
- сделайте телефон ссылкой `tel:`;
- место проведения оставьте обычным текстом.
