# Контент для задания 1B

Не нужно придумывать собственный текст. Перенесите данные в подходящие HTML-элементы и добавьте указанные БЭМ-классы.

## Навигация

| Текст      | Ссылка      |
| ---------- | ----------- |
| О событии  | `#about`    |
| Спикеры    | `#speakers` |
| Расписание | `#schedule` |
| Контакты   | `#contacts` |

Классы:

- `navigation site-header__navigation` — для `nav`;
- `navigation__list` — для `ul`;
- `navigation__item` — для каждого `li`;
- `navigation__link` — для каждой ссылки.

- `schedule__caption`;

Используйте:

- `address` с классом `contact-card__details`;
- `ul` с классом `contact-list`;
- `li` с классом `contact-list__item`;
- подпись с классом `contact-list__label`;
- ссылку с классом `contact-list__link`;
- обычное значение с классом `contact-list__value`.
